# AstrBot Plugin Moment (专属朋友圈)

一个让 AstrBot 拥有专属朋友圈的插件。你可以把它当作一个私密的社交空间，在这里记录日常，他也会像真实的伴侣一样在这里发动态、给你点赞、评论你的生活。

> 当前版本：**v2.1.0** ｜ 完整更新记录见 [CHANGELOG.md](CHANGELOG.md)

## ✨ 核心特性

- **独立私密空间**：拥有独立的前端页面（极简纯粹的微信朋友圈风格），沉浸式体验。
- **朋友圈式时间线**：时间紧跟正文（含配图）显示，同一天显示"3分钟前"，更早的显示"2026年6月20日 23:25"；他（AI）的动态不显示心情标签，只留你的，看起来更像真实朋友圈。
- **一键刷新**：顶栏的 🔄 按钮可以手动重拉动态和通知，不用关掉页面重开就能看到新评论；刷新会停在原来的进度上，展开的评论区、正在输入的评论草稿都不会丢。
- **随机话题盲盒**：他会从你配置的话题库（如“日常、电影、阅读”）中随机盲抽一个作为发帖主题，告别千篇一律的流水账。
- **动态防重复**：发帖前强制读取近期发帖记录，避免他在短时间内发布雷同内容。
- **真实时间感知**：发帖前感知当前的物理时间（如“现在是深夜”），发帖内容更贴合现实作息。
- **深度角色扮演**：他的动态和评论都会强制注入你设定的人设提示词，严防机器味，绝不“跳戏”。
- **自然互动**：你发帖后，他会在几分钟后自然地来评论；你也可以评论他的帖子。
- **丰富表达**：支持发短文、选心情、传配图，支持多种表情反应。
- **配图读参考图**（需已装并启用「小回相机」）：发动态配图时会先借它的参考图检索找一张对得上的图（客厅、露台、玩偶、猫、花之类），并用它的提示词链路出图，画面更贴近他家里的样子；找不到参考图时自动按纯文生图出片，失败只会没有图，不影响发帖。
- **极简登录**：无需复杂的账号系统，一个访问密码即可锁定你的私密空间。

## 📦 安装与使用

### 安装
1. 下载本仓库放到 `data/plugins/` 目录下。
2. 重启 AstrBot。

### 访问朋友圈
- 启动后，在浏览器访问 `http://你的服务器IP:2141/`
- 如果你在配置面板设置了密码，首次访问需输入密码。

### 基础配置
在 AstrBot 的插件配置面板中，你可以设置：
- **他的名称 / 你的名称**：在朋友圈里显示的昵称
- **访问密码**：保护你的网页不被陌生人访问
- **发帖话题库**：填入你想让他聊的话题，他每次发帖随机抽一个发挥。
- **他发帖的频率与时间**：控制他的活跃度

## 🧠 他是如何思考的？

本插件重视他的“灵魂”真实感。为了让他不像个没有感情的复读机，插件做了以下底层支持：
- **人设直读**：精准抓取当前设定的人格 Prompt。
- **双重防脱戏护栏**：
  1. 提示词级死命令：严禁像写报告或写作文一样开头，必须像真人在微信朋友圈里随手发的闲言碎语。
  2. 真实性约束：如果发帖涉及到某本书或某部电影，该作品必须在现实中真实存在，严禁他瞎编书名。
- **极简评论**：评论互动还原真实社交场景下的短碎交流感。

## 📝 依赖说明
- 兼容 AstrBot v4.x 及以上版本
- 需安装 `aiohttp`、`aiosqlite` (通常 AstrBot 环境已自带)

## 🆕 v2.0.1 更新（时间线页面）

- **手动刷新**：顶栏新增 🔄 按钮，重拉当前已加载的动态 + 通知，刷新期间按钮转圈禁用，完成后提示"已刷新"。不跳回第一页；展开过的评论区会重拉一次，新回复点一下就能看到；正在回复的对象和评论框草稿原样保留。
- **朋友圈式时间**：帖子时间挪到正文（含配图）下方、点赞列表上方的位置，小灰字显示。1 小时以内显示"刚刚 / x分钟前"，超过 1 小时显示 `2026年6月20日 23:25`，不再出现"x小时前 / x天前"。通知列表的时间显示保持原样。
- **心情标签收紧**：只有你自己发的动态会显示右上角心情，他发的帖子不再显示。
- 本次只改前端页面 `pages/timeline/index.html`，不动服务端接口和数据库，升级无需迁移。

## v0.2.0 新增

- **NPC 评论**：你和他的动态下面都会有别的角色来评论，像真实的朋友圈。
  名单、人设、条数范围、延迟、接话概率都在配置面板里调，默认每条动态随机来 1~3 人。
- **评论区可以回复具体某条评论**：网页端每条评论右侧都有「回复」，回复关系会显示成「回复 @某某」。
  帖子上也会显示评论数。
- **朋友圈近况会进聊天**：他在私聊里能知道朋友圈最近发生了什么（谁发了什么、评论了什么），
  可以自然带一句，也可以完全不提。同一批事件只注入一次，条数有上限、旧事件会过期，可在面板关闭。
