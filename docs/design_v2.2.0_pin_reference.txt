Moment v2.2.0 设计文档：面板配置固定参考图 + 多图直传小回相机
================================================================

一、需求来源
------------
用户反馈：朋友说 moment 调用「小回相机」出图时，应该能在面板里自己
配置放几张参考图——因为小回相机本来就能一次读多张参考图，
而 moment 现在只喂一张（多张时还要先自己拼成一张对照表）。

二、现状问题
------------
1. 参考图最多 1 张：`_pick_reference()` 内部每一步都 limit=1/2，
   最终只用 `refs[0]`；面板也没有「固定参考图」这一项，
   只能填一个 `image_reference_hint` 关键词。
2. 多张时强行拼图：`_merge_references()` 调相机的
   `_make_grouped_reference_sheets()` 把多张压成一张 sheet。
   把三张不同主体的图拼成一张，等于让模型在一张图里分辨
   「哪个是脸、哪个是衣服、哪个是玩偶」，信息互相干扰，
   细节反而更容易糊。
3. 相机其实支持多图：它的 `_call_edits()` 会把 list 里每一张
   都作为独立的 image 字段发给 edits 接口（
   `for one_ref in ref_paths: form.add_field("image", ...)`）。
   moment 白白绕开了这条能力。

三、本次改动
------------
1. 面板新增 3 个配置（`_conf_schema.json`，「动态配图」区）：
   - `image_reference_pin`（string，默认空）
     固定参考图，填参考库里的文件夹名或图片文件名，
     多个用英文逗号分隔，如「脸部,服装,兔球球」。
     每次出图都会带上这几张，人和穿搭不会每张都漂。
   - `image_reference_max`（int，默认 3，范围 1~4）
     单次最多带几张参考图（含自动匹配的那张），超出按顺序丢弃。
   - `image_reference_multi_direct`（bool，默认 true）
     多张参考图是否原样直传相机；关掉则回到旧的拼合对照表。
2. `core/image_bridge.py` 新增：
   - `_pinned_tokens()` / `_pinned_references()`：
     逐条解析固定参考图。命中文件夹名 → 借相机的
     `_pick_from_folder_by_text()` 进该文件夹挑一张；
     否则按文件名在参考库里找（`_find_reference_file()`，
     精确名 → 包含匹配两级兜底）。单条找不到只跳过并记日志。
   - `_merge_ref_list()`：固定参考图在前、自动匹配在后，
     去重后按 `image_reference_max` 截断。
   - `_reference_payload()`：决定交付方式——
     1 张 → 单张 Path；多张且直传开启且相机有 `_call_edits`
     → 直接传 list；否则 → 走旧拼图。
   - `_camera_supports_multi_reference()`：能力探测用
     `callable(getattr(camera, "_call_edits", None))`，
     不比对版本号字符串（对方版本号不可控）。
   - `_call_camera()`：多图直传失败时，用相机的
     `_make_grouped_reference_sheets()` 拼一张再试一次；
     仍失败才走原有的「相机自己允许才降级无参考」逻辑。
3. 日志口径：写明这次带了几张、哪几张、是直传还是拼图，
   出图失败的原因一眼可查。

四、边界与安全
--------------
- 固定参考图只接受「参考库内部」的文件：token 取最后一段做名字匹配
  （`脸部/主参考.png` → `主参考`），再在 `reference_dir` 里
  `rglob` 查找，填库外绝对路径不会被读取。
- 相机的参考库为空、目录读不到、任一方法不存在：一律安静跳过，
  退回「只有自动匹配的那张」或「无参考图」的旧行为。
- 不改「小回相机」任何文件与配置，也不动 moment 的数据库、
  接口与网页端。
- 相机的 edits 请求体积随张数上涨，故上限锁在 4；默认 3 张
  即可同时锁脸 + 穿搭 + 一个物件。

五、测试
--------
`tests/test_image_bridge.py` 新增 8 条（原有用例全部保留）：
- 固定参考图与自动匹配图一起直传（且不拼图）
- 固定参考图按文件名命中
- 超过张数上限时按顺序截断
- 关掉直传开关 → 回落到拼合对照表
- 多图直传失败 → 自动用拼合表重试一次并成功出图
- 固定参考图名字填错 → 只跳过该条，不影响出图
- 填库外路径 → 不读取，按无固定参考图处理
- 原有 55 条：禁用、抽签、超时、降级、拼图等行为不变

六、版本
--------
新功能，minor：v2.1.1 → v2.2.0。
