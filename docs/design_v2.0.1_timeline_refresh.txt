# v2.0.1 时间线页面改动设计（手动刷新 / 朋友圈式时间 / 心情标签）

## 1. 需求
1. 页面顶栏加一个手动刷新按钮，解决"必须关掉页面重开才能看到新回复"。
2. 帖子时间像真实朋友圈一样紧跟在正文（含配图）下方、点赞/表情列表上方，1 小时以内显示相对时间，超过 1 小时显示 `2026年6月20日 23:25`，不再显示"x小时前 / x天前"。
3. 他（AI）发的动态，右上角心情标签不显示。

## 2. 影响面
只改前端单文件：`pages/timeline/index.html`（HTML + CSS + 内嵌 JS）。
不改 `core/standalone_server.py`、不改数据库结构、不改配置项，无需迁移、无需重载数据库。

## 3. 实现
### 3.1 刷新按钮
* `.cover-actions` 内新增 `<button id="refreshBtn" title="刷新">🔄</button>`，与现有按钮同尺寸圆形样式。
* 新增 `#refreshBtn.spinning` 旋转动画，刷新期间按钮禁用 + 转圈，完成后 `toast('已刷新')`。
* 点击逻辑：`refreshPosts()` → `loadNotifications()`。

### 3.2 refreshPosts()
* 拉取范围 = `max(PAGE_SIZE, 当前已加载条数)`，`offset=0`，因此刷新后停留在同样的加载进度，不跳回第一页；`totalPosts` 同步更新，`loadMoreBtn` 状态由 `updateLoadMore()` 重算。
* 刷新前记录：展开中的帖子 id、评论草稿（`comment-input-<id>` 的值）、回复目标 `_replyTo`。
* 对展开中的帖子调用 `/api/comments` 重拉评论，保证新回复立刻可见。
* `renderPosts()` 后还原：回复目标（仅当该评论仍存在时调 `startReply`）、评论草稿文本。

### 3.3 时间显示
* 卡片结构：时间从 `.post-header` 移到正文（含配图）之后、点赞/表情列表之前，新增 `.post-time-content`（上 4px / 下 10px 间距），与真实朋友圈一致（正文下的小灰字）。
* `formatTime(ts, forPost = false)`：新增 `forPost` 参数。帖子卡片传 `true`，超过 3600 秒即返回 `2026年6月20日 23:25`；1 小时内仍为"刚刚 / x分钟前"。
* 通知列表继续用默认行为（刚刚 / 分钟 / 小时 / 天前），不受影响。
* 新增 `pad2()` 小工具，替换原来重复的补零代码。

### 3.4 心情标签
* `renderPostCard` 中 mood 由 `post.mood ? ... : ''` 改为 `!isAI && post.mood ? ... : ''`，即 AI（沈星回）动态不渲染心情标签。

## 4. 风险与回退
* 风险：全量重绘会重建 DOM，故做了草稿/回复状态的快照还原；若刷新时正在拖拽图片预览等临时状态，仍会重置（概率极低）。
* 回退：`data/plugins/_backups/xavier_moment_index_20261003_130814.html.bak` 覆盖回 `pages/timeline/index.html` 即可。

## 5. 测试点
1. 正常打开页面，无报错，时间线正常。
2. 点 🔄：按钮转圈、底部提示"已刷新"、条数不回到 20 条、滚动位置基本不动。
3. 展开某帖评论 → 在私聊里让他评论一句 → 点 🔄，新评论出现。
4. 在评论框输入文字不发送 → 点 🔄，文字还在。
5. 帖子时间紧跟正文/配图下方、点赞列表上方：1 小时内的显示"x分钟前"，超过 1 小时的显示 `2026年10月3日 01:20`；头像旁与卡片底部都没有时间。
6. 他发的动态右上角没有心情标签，自己发动态仍有。
7. 切深色模式、通知面板照旧可用。
